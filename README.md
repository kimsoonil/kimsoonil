# 👋 안녕하세요, 김순일입니다!

💻 **프론트엔드 개발자** | 7년차 개발자

프론트엔드 리더십 및 기술 혁신을 주도하는 개발자입니다.  
프론트엔드 챕터를 리딩하며 기술 표준 확립과 팀 역량 강화에 집중해왔습니다. 팀의 기술 스택 선정과 코드 컨벤션을 주도했고, 다양한 개발 문화를 포용하며 동료들과 건설적인 코드 리뷰를 통해 코드 품질을 일관되게 유지했습니다. 주니어 개발자들의 멘토링과 페어 프로그래밍을 통해 팀 전체 역량 향상에 실질적으로 기여했습니다.

프로젝트 안정성을 위해 VITest와 React Testing Library 기반의 테스트 코드 작성 문화를 정착시켰으며, 프론트엔드 아키텍처 설계와 성능 최적화를 주도하여 사용자 경험을 개선했습니다. 특히, Cursor 등 AI 도구를 개발 프로세스에 적극 도입하여 반복 작업을 자동화하고, 확보된 시간을 코드 리뷰 및 문서화에 재투자하며 생산성과 품질 두 마리 토끼를 모두 잡았습니다.

## 💡 주요 활동

### 🔄 리팩토링/코드 리뷰
다양한 개발자와 다양한 개발 습관, 다양한 코드가 있다고 생각합니다. 그래서 동료들과 코드에 대해 의논하는 것을 좋아하며 다른 개발자가 사용한 코드를 써보고 더 좋은 코드가 있으면 적극적으로 수용하고 리팩토링하며 제가 경험해봤던 코드들을 이야기하며 개발 습관 등을 추천해 줍니다.

### 🧑‍💼 채용 프로세스 참여
채용 프로세스에 참여한 경험이 있습니다. 직접 아이디어를 요구하는 문제를 출제하기도 하고 기술 인터뷰에 참여하고 있습니다.

### 🤖 신기술을 활용한 개발 프로세스 향상
최근에는 AI 기술을 적극적으로 개발 프로세스에 도입하고 있습니다. 특히 Cursor 에디터를 활용하여 코드 작성 속도를 크게 향상시키고, CLI 환경에서도 AI 도구를 접목시켜 반복적인 작업을 자동화하고 있습니다. 바이드코딩을 통해 확보된 시간을 코드 리뷰와 문서화 작업에 투자하여 코드 품질과 유지보수성을 높이고 있습니다.

### 🧪 코드 품질 향상
프로젝트 안정성과 유지보수성을 높이기 위해 VITest를 활용한 단위테스트와 React Testing Library를 활용한 통합테스트 코드 작성을 도입했습니다. 이러한 테스트 방식을 통해 기능 개발 단계에서 발생할 수 있는 버그를 조기에 발견하고, 리팩토링 과정에서의 회귀 오류를 방지하고 있습니다.

### 👥 개발 문화
체계적인 개발 문화를 좋아합니다. 데일리 스크럼을 통해 팀원들과 진행 상황을 공유하고, 스프린트 플래닝에서는 다음 스프린트의 작업 우선순위와 스토리 포인트를 함께 결정합니다. 특히 스프린트 회고를 통해 팀의 강점은 더욱 강화하고 개선점은 신속하게 수정하는 프로세스를 정착시켰습니다.
