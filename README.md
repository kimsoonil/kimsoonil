# 김순일 · 프론트엔드 개발자

커머스와 운영 관리 화면을 개발해 왔습니다. React·TypeScript·Next.js를 주로 사용합니다.
주문·배송·재고·반품·정산처럼 여러 단계가 이어지는 업무를 화면으로 구현하고, 공통 UI와 테스트를 다뤘습니다.
